Com histórico na instrução técnica e uma visão integrada do ciclo de vida de software, conecto os ecossistemas de **Qualidade (QA)** e **Desenvolvimento Full Stack**. Meu objetivo é construir códigos sólidos, arquitetar automações eficientes e garantir entregas seguras.

No meu dia a dia profissional, foco na governança de código através do gerenciamento de versionamento (Git/GitHub), monitoramento de Pull Requests e coordenação de deploys entre múltiplos ambientes.

Sempre em busca de aprender e evoluir, dedico meu tempo a aprimorar minhas competências técnicas para antecipar soluções e agregar valor aos processos desenvolvido.

---

## 🛠️ Stack Tecnológica & Processos

### 🧪 Garantia de Qualidade & Automação
* Automação de Testes E2E com **Cypress** (Arquitetura POM)
* Testes de Carga e Desempenho com **k6**
* Testes Manuais, Planejamento e Análise de Requisitos
* Cultura de Qualidade e Garantia em todo o ciclo de desenvolvimento

### 🚀 Desenvolvimento de Software & Processos
* **Front-End:** HTML5, CSS3, JavaScript (ES6+), React
* **Back-End:** Node.js, REST APIs, Python, Java (POO)
* **Banco de Dados & Versionamento:** MySQL / SQL, Git & GitHub (GitFlow), Monitoramento e Gestão de Ambientes
